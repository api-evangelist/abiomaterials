# A-Bio Materials (에이바이오머티리얼즈)

> A-Bio Materials Co., Ltd. is a South Korean life-science company, founded in 2020,
> that develops and manufactures exosome-derived bioactive materials for cosmetics,
> aesthetics and medical devices. Its North American arm, ABio materials USA Inc.
> (Tustin, California), is the official importer and distributor for the region and
> operates the company's English-language storefront at a-biousa.com.

This file was GENERATED by API Evangelist from probed, first-party surfaces. The
company does not publish an llms.txt of its own: /llms.txt returns 404 on
a-biousa.com and a soft-404 on a-bio.co.kr.

## What this company does and does not publish

A-Bio Materials runs **no developer programme**. There is no developer portal, no API
documentation, no API reference, no getting-started guide, no SDK, no CLI, no API keys,
no OAuth, no sandbox, no status page and no changelog. No OpenAPI, Swagger, GraphQL,
AsyncAPI, gRPC or WSDL contract is published on any host.

What it does serve — verified live on 2026-09-06 — is a small set of machine-readable
surfaces produced by the WordPress/WooCommerce stack behind its North American
storefront. These are **platform-authored**, not designed by the company, and they
describe site content and its product catalogue rather than a business API.

## Machine-readable surfaces (all anonymous unless noted)

- [API catalog](https://a-biousa.com/.well-known/api-catalog): RFC 9727 linkset
  (application/linkset+json) naming the WebMCP manifest and execute endpoint.
- [WebMCP tool manifest](https://a-biousa.com/wp-json/g99-webmcp/v1/manifest): six
  tools with JSON Schema inputs — get_site_context, search_site,
  discover_site_content, get_public_page_details, get_page_by_url, get_full_sitemap.
- [WebMCP execute endpoint](https://a-biousa.com/wp-json/g99-webmcp/v1/execute): POST
  {"tool": "...", "arguments": {...}}; returns MCP-style content envelopes. Not JSON-RPC.
- [WooCommerce Store API](https://a-biousa.com/wp-json/wc/store/v1/products): the real
  product catalogue (39 products), with prices, stock, categories, brands and reviews.
- [WordPress content API](https://a-biousa.com/wp-json/wp/v2/posts): blog posts and pages.
- [REST route index](https://a-biousa.com/wp-json/): 1,002 registered routes.
- JSON-RPC MCP endpoint at https://a-biousa.com/wp-json/mcp/mcp-adapter-default-server —
  **auth-gated**: tools/list returns HTTP 401 rest_forbidden with no WWW-Authenticate
  header, so its tool schemas cannot be read anonymously.

## Runtime conventions

- Versioning: namespace-in-path, /wp-json/<namespace>/v<N>/.
- Pagination: page and per_page (max 100, enforced with HTTP 400); X-WP-Total,
  X-WP-TotalPages and a Link rel="next" header.
- Errors: {"code","message","data":{"status"}} — not RFC 9457 problem+json.
  Observed codes: rest_no_route, rest_forbidden, rest_invalid_param,
  woocommerce_rest_product_invalid_id, tool_not_found.
- Rate limits: none published, none signalled — no RateLimit-*, X-RateLimit-* or
  Retry-After header on any observed response.
- Idempotency: none. Reversibility: not applicable — the anonymous surface is read-only.
